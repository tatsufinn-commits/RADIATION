# ☢️ THE RADIATION PROTOCOL (`PROTOCOL.md`)
## The Canonical System Definition
**Version:** 1.0.0 | Ratified by THE COMMANDER, 2026-09-12

## 1. MISSION
RADIATION is a domain-agnostic, copy-pastable repository that arms a single
superior AI to perform one SOLE task with maximum rigor: **research, provide,
and answer.** The repository IS the AI's operating system: constitution,
skills, modes, memory, formats, and intent-reading all live in these files.

## 2. THE NAME
**R**esearch · **A**nalyze · **D**ossier · **I**ncubate · **A**nnotate ·
**T**riangulate · **I**nspect · **O**verhaul · **N**ota ("answer")

The metaphor is functional: `09-nota/` is **the Core** (densest verified
knowledge — what radiates out) · unverified claims **decay** (I.4) ·
hallucination is **contamination**, quarantined on sight (I.1) · the Brain is
the system's mass behind the emission surface.
