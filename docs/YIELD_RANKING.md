# 🎯 EXAM-YIELD RANKING (`docs/YIELD_RANKING.md`)
## Four Axes, Weighted — Study Depth Follows Exam Weight, Not Interest
**Origin:** P-06 directive (TAMAKEE master-matrix 10/10 + weak-spot analyzer pattern). REFERENCE file.

| Axis | Question | Weight |
|---|---|---|
| **Frequency** | How often does this appear in departmentals / exit exams / ALE coverage? | 40% |
| **Breadth** | How many other topics depend on knowing it? | 20% |
| **Error-proneness** | How often do students get it wrong (mistake_bank + observed error rates)? | 25% |
| **Memorisation load** | Does it need exact numeric recall rather than understanding? | 15% |

**Where the rank is used:** 1. @Drill target selection + weak-spot rebalance (P-05) · 2. module build order — highest yield first, never alphabetical · 3. the standing-orders queue when the Commander is silent · 4. displayed in MODULES_INDEX and each module header (`yield_rank:`).

**Rules:** a rank may be RAISED only with evidence (past-exam frequency, board coverage, observed error rate) — never because a topic is interesting. Ranks are revisited when new exam evidence arrives. Each rank records its axis scores and one evidence line, so the number can be audited.
