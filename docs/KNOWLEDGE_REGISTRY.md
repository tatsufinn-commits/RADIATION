## DIVISION OF LABOR (stated here and in `01-research/REFERENCES.md`)
`01-research/REFERENCES.md` = the **SOURCE** registry (S-n / SRC-n: where matter came from).
THIS file = the **OBJECT** layer (K-n: the knowledge things themselves — a law, a
table, a module, a reviewer — each answerable for authority, currency, supersession,
conflicts, and consumers). A K-ID is a **bookkeeping pointer, never a grade and never
a citation** — deliverables still cite statute/rule/table (I.2).

## FROZEN ID DOMAINS
`K-LAW-*` statutes & IRRs · `K-STD-*` codes/standards · `K-CUR-*` curriculum material ·
`K-BK-*` textbooks · `K-MOD-*` canonical modules (P-06) · `K-MTH-*` procedures/formulas ·
`K-REF-*` reference data · `K-EXT-*` external collections & hubs.
Extending this list = append a line here (II.2); never repurpose a domain.

Fields per `scaffolding/improved/form_knowledge-record.md` (rev-note there; core/
placement awaits ratification). **Honesty rules:** unknown `Last verified` stays
BLANK + status `UNVERIFIED`; `RECORDED-NOT-HELD` = known & cited, not in repo/collection;
`SUPERSEDED` rows keep their tree entry (II.4); one object = one row = ONE canonical path.
`Depth` values await P-06's scale — provisional `—` until it lands.
