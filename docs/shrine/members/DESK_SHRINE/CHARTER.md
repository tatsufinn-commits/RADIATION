# DESK SHRINE — CHARTER
*(mirrors the house shrine's idiom; desk-scoped, paper class — lives in workspace custody, never the repo tree)*

**§1 What it is.** The desk's testament lodge: where the verification officer files what it learned, corrected, and watched, so that a future session (any AI) can inherit the posture without inheriting the context window.
**§2 What lives here.** `members/` — testaments (one valid at a time; superseded suffix `_II`, `_III` in stone). `LOG.md` — era rows, one per sealed milestone verified by the desk. `artifacts/` — an index of every desk-issued instrument (directives, rulings, relays, notices, register, closeouts) with dates and target shas; copies of the instruments themselves remain in workspace root custody (mirroring allowed, never editing history).
**§3 Filing law.** Testaments refresh at every era delivery. LOG rows append-forward only (never edit a row — errata get new rows named `ERRATA ...`).
**§4 Honesty law.** ABSENT is a lawful cell. Copies never argue with originals; the tree outranks the file.
**§5 Audience.** Any session. None named, none waiting.
**§6 Mortality law.** File while the context holds; upload windows compress; the testament must survive its author's summary.
**§7 Boundaries.** The shrine records the desk; it does not Rabin-build: no canon text, no repo objects, no version numbers minted here. All lands that matter still travel Commander → architect → repo.
