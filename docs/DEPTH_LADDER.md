# 🪜 THE DEPTH LADDER (`docs/DEPTH_LADDER.md`)
## Levels 1–5 — Objective, Checkable Completion Criteria
**Origin:** P-06 directive. REFERENCE file — never in the boot set.
**The level is earned by content, never by effort or bytes. Machine-checked criteria are marked ⚙ (validator check 18).**

| Level | Name | ALL criteria required |
|:---:|---|---|
| **1** | STUB | Purpose stated · K-ID(s) ⚙ · source list · explicit `LIMITS` line ⚙. Nothing asserted beyond what the source states. |
| **2** | OUTLINE | + all mandatory headings populated ⚙ (WHY THIS MATTERS / CORE CONTENT / AUTHORITY TABLE / NUMBERS TO KNOW / WORKED EXAMPLES / EXAM TRAPS / LINEAGE & LIMITS) · key terms defined · every claim graded |
| **3** | WORKING | + ≥1 worked example with visible steps ⚙ · ≥4 traps explained ⚙ · glossary ≥10 terms ⚙ · citations with locators (P-07 format; provisional until P-07 lands) |
| **4** | ADVANCED | + ≥2 worked scenarios, one applied/design ⚙ · ≥8 traps ⚙ · formulas with derivations or stated provenance · ≥2 comparative/tabular references · lineage block |
| **5** | COMPREHENSIVE | + ≥10 traps ⚙ · case studies (PH context where applicable) · 10-item drill with verified key (P-05 format) ⚙ · ≥1 diagram/worked drawing description · registry row with last_verified + frequency · conflict check performed and recorded |

**Rules:** level recorded in module header (`depth_level:`) and MODULES_INDEX. A Level-N claim whose Level-N criteria are absent = **validator FAIL** (check 18), not opinion. An honest Level 2 beats a pretend Level 5. Depth follows YIELD (docs/YIELD_RANKING.md): a 4/10 topic at Level 2 is *correctly* built. Inventing case studies to reach Level 5 is I.1 contamination — the module is Level 4 and says so.
