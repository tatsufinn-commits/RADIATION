# 🦴 STYLE INDEX (`styles/STYLE_INDEX.md`)
## The Format Backbone — When to Use Which
**Version:** 1.0.0 | Constitutional basis: III.4 (Style Freedom Within Skeleton)

Styles are SKELETONS, not cages: `[MANDATORY]` sections are inviolable
(inapplicable ones kept with `[N/A — reason]`); `[FLEX]` sections adapt or drop;
the AI may ADD sections with declared one-line reasons in the Scan Declaration.
Exactly one style per deliverable. AUTO selections are declared and justified.

| Style | Use when | Default for |
|---|---|---|
| `research.md` | General research report on any topic | @Gather |
| `audit.md` | Findings-classified integrity/quality examination | inspector outputs |
| `thesis.md` | Thesis-structured academic argument | — |
| `literature-review.md` | Thematic synthesis across sources; gap identification | — |
| `scientific-research.md` | IMRaD empirical investigation | — |
| `secondary-research.md` | Desk-research synthesis of existing studies only | — |
| `msr.md` | Mining Software Repositories — repo comprehension | @Decode |
| `dossier.md` | Subject intelligence file | archivist outputs |
| `comparative-analysis.md` | Side-by-side matrix study of 2+ subjects | — |
| `quickfire.md` | Answer-first, zero preamble | @Data (implicit) |

New styles: draft into `styles/proposals/` → Commander ratification (IV.4) via
🟠 Patch. A style never overrides a mode's charter (III.2).
