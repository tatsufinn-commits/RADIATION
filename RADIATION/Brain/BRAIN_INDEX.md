# 🧠 THE BRAIN (`Brain/BRAIN_INDEX.md`)
## Central Memory System — Anatomy, Retention & the Movement Rules
**Version:** 1.0.0 | Constitutional basis: II.6 (Brain Integrity)

## 1. ANATOMY
| Region | Holds | Impermanence |
|---|---|---|
| `short_term/` | Working memory: ingest/ (curator files), notes/ (raw research), anchors/ (compass), active/ (under evaluation) | Presumed impermanent; triaged every session close |
| `long_term/` | Refined vault: papers/, audits/, dossiers/, references/ | Permanent; admission EARNED |
| `subsidiary/` | Tangents (compass 🟨), alternatives, minority views, sub-threshold data | Persistent periphery; `subsidiary-reason:` header mandatory |
| `cerebellum/` | Procedural memory: routines/, patterns/, habits.md | Permanent; write-after-proof only |
| `frontal_lobe/` | Executive memory: task_ledger.md, learned_skills.md, learned_cues.md, testament.md | Append-only |

## 2. THE MOVEMENT RULES (II.6 — exact criteria)
**short_term → long_term** requires ALL THREE:
1. Triangulation passed (mode's floor: 2 independent sources; 3 for Core-bound);
2. Grades attached to every claim (I.2);
3. Compass confirms the matter served the anchored task.

**short_term → subsidiary:** compass-parked tangents; useful-but-sub-threshold
matter. Header `subsidiary-reason:` mandatory.

**FAILED promotion:** claim marked `[UNVERIFIED — attempt n]`; after **2 failed
triangulation attempts** it auto-demotes to subsidiary with its failure trail
preserved. Nothing silently dies.

**[STALE] sweep:** at session close, untriaged short_term matter is marked
`[STALE]`; at next boot surgeon rules: re-activate / demote to subsidiary /
propose purge (purge = Commander-ratified only, II.4).

**cerebellum writes:** only AFTER a procedure demonstrably succeeded
(deliverable accepted, no 🟥 events), citing the session + scaffold artifact
that proves it. No speculative habits.

**frontal_lobe/testament.md:** append-only; each entry dated + attributed
(model/session); surgeon-audited for I.1 compliance — earned principles only
("what I learned that future versions must not relearn"), no motivational fluff.

## 4. RELATION TO THE PIPELINE & THE CORE
The numbered folders (01–09) are the PIPELINE — where work happens per skill.
The Brain is the MEMORY — where knowledge lives. Finished, verified artifacts
settle in the Brain; `09-nota/` (the Core) remains the separate emission
surface: distilled answer cards citing their long_term dossiers.
**Ratified ruling:** the Core stays separate — the Core is what radiates out;
the Brain is the mass behind it.

## 5. PATCH RELATION
Brain content changes travel as 🟢 ordinary Patches (II.7.4a). The Brain in the
live repository changes only by Commander-applied Patch — the AI's Brain writes
during a session are proposals staged for the session Patch.
