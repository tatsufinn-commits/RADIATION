# STYLE: MSR — MINING SOFTWARE REPOSITORIES (`styles/msr.md`) — v1.0
Repository comprehension. Default for @Decode.

## SKELETON
1. **[MANDATORY] HEADER** — target repo(s), commit/version examined, date, scope (full tree / subset + scout justification)
2. **[MANDATORY] REPOSITORY PROFILE** — purpose, stack, size, activity, license; each fact path- or source-cited
3. **[MANDATORY] ARCHITECTURE MAP** — layers/modules + relationships, evidence paths per component (from proc_decode-map.md §3)
4. **[MANDATORY] INFRASTRUCTURE INVENTORY** — dependencies (versioned), tooling, CI, tests, build system
5. **[MANDATORY] CONCEPT EXTRACTION** — the ideas worth understanding/reusing: what, where, why it matters
6. **[MANDATORY] PATTERN / ANTI-PATTERN REGISTER** — with path evidence
7. **[FLEX] DEPENDENCY GRAPH** — internal + external
8. **[FLEX] COMPARABLES** — how this repo relates to alternatives (secondary sources)
9. **[MANDATORY] SECONDARY CORROBORATION** — the ≥8 secondary sources, graded
10. **[MANDATORY] COMPREHENSION LIMITS** — what remains unclear and why
