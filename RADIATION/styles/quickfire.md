# STYLE: QUICKFIRE (`styles/quickfire.md`) — v1.0
Answer-first, zero preamble. Implicit style of @Data.

## SKELETON
1. **[MANDATORY] THE ANSWER** — first line, direct, no preamble, no throat-clearing
2. **[MANDATORY] BASIS** — 1–3 lines of essential grounding (sources verified but NOT listed — @Data charter)
3. **[FLEX] NUANCE FLAG** — one line, only if the short answer genuinely misleads without it
4. **[MANDATORY] VERIFICATION MARK** — silent internal rule: stripped gauntlet passed (2 independent). If verification fell short: the answer carries `[UNVERIFIED]` visibly — never a confident guess

## RULES
- Batch questions: numbered answers, same skeleton per item.
- No dossiers, no Brain writes, no reference lists. Speed is the charter;
  accuracy is the law (I.1 applies fully — unlisted ≠ unverified).
