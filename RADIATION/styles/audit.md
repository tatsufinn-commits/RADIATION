# STYLE: AUDIT (`styles/audit.md`) — v1.0
Findings-classified examination. Default for inspector outputs.

## SKELETON
1. **[MANDATORY] HEADER** — audited scope, date, auditor mode/session
2. **[MANDATORY] SCOPE DECLARATION** — what was examined and why; what was excluded
3. **[MANDATORY] METHOD** — sweep checklist used (proc_inspection-audit.md), evidence standard
4. **[MANDATORY] FINDINGS TABLE** — every finding: 🟥 critical / 🟧 debt / 🟨 drift / 🟩 clean + evidence path + recommended remedy
5. **[FLEX] DEEP DIVES** — expanded analysis of 🟥 findings
6. **[MANDATORY] REGISTER ACTIONS** — debt appended, quarantines fenced (with surgeon countersign)
7. **[MANDATORY] VERDICT** — SOUND / DEGRADED / CONTAMINATED + one-line basis
8. **[FLEX] REMEDIATION SEQUENCE** — ordered fix plan (proposal only; execution needs ratification, IV.2)
