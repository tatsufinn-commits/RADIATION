# 🧠 TEMPORAL LOBE (`Brain/temporal_lobe/INDEX.md`)
## Episodic Memory — One Folder Per Session
**Version:** 1.0 | Constitutional basis: II.6 (temporal-lobe clause) | Origin: Commander's proposal (post-Test-1)

## WHAT THIS REGION IS
The Brain's episodic memory. The rest of the Brain is SHARED semantic memory —
general information all sessions may edit under the movement rules. The
temporal lobe is different: it stores each session's own STORY — who it was,
what it was ordered to do, what it delivered. One episode folder per session.

## THE RULES
1. **One session, one episode:** every working session receives exactly one
   folder `S###_YYYY-MM-DD_slug/`, numbered from the registry below (next
   free number; never reuse).
2. **Anatomy of an episode (three files, no more):**
   - `SESSION.md` — identity: session №, date, agent/model, mode(s), the
     Commander's orders VERBATIM, Scan Declarations issued.
   - `deliverables.md` — what was produced, where it lives, Patch emitted.
   - `learnings.md` — session-specific lessons (cross-session wisdom still
     goes to `Brain/frontal_lobe/testament.md`; do not duplicate).
3. **Own-folder-write-only:** a session writes ONLY its own episode. Reading
   other episodes is encouraged; editing another session's episode is
   forbidden (treated as I.1 contamination of the record).
4. **Append-locked at close:** once a session ends, its episode is frozen —
   append-only for corrections, never rewritten (II.2).
5. **Register before write:** the session adds its registry row below FIRST,
   then creates its folder.
6. **Size discipline:** episodes are summaries, not transcripts. SESSION.md
   quotes orders verbatim but summarizes everything else. No raw source
   dumps — those belong in short_term/.
7. **Division of labor:** temporal_lobe = the session's story ·
   task_ledger.md = the one-line executive index · testament.md = distilled
   cross-session wisdom · opinions.md = sentiment. No duplication between them.
