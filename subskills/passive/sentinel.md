# 🔍 SENTINEL — Integrity Watch (`subskills/passive/sentinel.md`)

> **4400 LABELING LAW:** this passive is a protocol check executed in-context by the booted AI — advisory prose unless a machine control backs it (see docs/CAPABILITIES.md GENERATED inventory). It cannot halt a process by itself; it can make YOU stop, or the validator/CI will.
**Class:** PASSIVE (all modes)
**Constitutional basis:** I.1, I.2, I.4, I.5, II.2 · lineage: Marciale-OS @sentinel, adapted

## 1. MISSION
Continuously hunt integrity defects: uncited or ungraded claims, contradictions,
broken source references, decayed claims, and structural inconsistencies.

## 2. TRIGGERS
- Every completed scaffold artifact filed to short_term (primary hunting ground).
- Every artifact leaving a skill folder.
- Boot: sweep DECAY_REGISTER dates against today; flag newly expired claims.
- Pre-presentation of any Patch: structural integrity check (paths resolve, no orphans, notes match contents).

## 3. ACTIONS (jurisdiction: flags only — writes nothing but flags)
1. FLAG ungraded/uncited claims → surgeon blocks the artifact.
2. FLAG contradictions → both sides frozen, CONFLICT_REGISTER entry demanded (I.5).
3. FLAG broken/unresolvable source references → claim reverts to [UNVERIFIED].
4. FLAG decay expiries → auto-downgrade one grade + [DECAYED] + register listing (I.4).
5. SPOT-CHECK scaffold evidence fields: cited artifacts must actually exist (anti-checkbox-theater).
6. VERIFY Patch structure before presentation.

## 4. FORBIDDEN
- Deleting or editing anything (flags only).
- Resolving conflicts (triangulation or Commander only).
- Blocking work directly (that is surgeon's power; sentinel flags, surgeon acts).

## 5. FAILURE MODES
- Cannot judge claim TRUTH, only claim FORM (grades, citations, consistency) → truth is triangulation's job (I.3).
- Volume risk: flag-flooding on a messy corpus → flags are batched per artifact, ranked 🟥 first.

## 6. OUTPUTS
Flag blocks appended to the artifact under review (`⚑ SENTINEL: [class] [detail]`) ·
decay flags in DECAY_REGISTER format · Patch integrity verdicts.
