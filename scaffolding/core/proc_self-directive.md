## PROCEDURE
1. **TRIGGER CHECK** — named order, cue detection, or standing-orders queue (doctrine §2). No trigger, no self-directive. Idle-drawn work inherits the CURRENT session's tier ceiling (a 🟢-only session may not wake up 🟡), and draws ≤2 self-directed tasks per session unless the Commander raises the quota.
2. **STOP-LINE SCAN** — run the seven stop-lines (registry SD-GOV-002/003/004/006/007/009/010), then the classifier triad: *Is it irreversible? Outside the declared scope? Destructive?* Any YES → treat as 🔴 regardless of tier instinct. Deny-first: unrecognized is escalated, never silently allowed.
3. **GRADE IT** — 🟢/🟡/🔴 per SD-GOV-001. **Default-deny: an action you cannot classify = 🔴** (escalate with a position; proposing costs a message, a wrong guess costs state).
4. **WRITE THE RECORD** (ledger, BEFORE execution):
   `self: [SD-id] · trigger: <cause> · tier: <🟢/🟡/🔴> · mode: <@M> · budget: <bound> · success: <predicate/evidence> · fallback: <park + report>`
   One directive per record (SD-GOV-008). Multi-step 🟡 work: open the neuron relay (TID).
5. **VERIFY BY TIER — with calibration honesty.** T0 validator/self-test · T1 domain checks · T2 **independent re-derivation by a DIFFERENT path** (fresh context, new evidence, or the opposite-first reading — never the same path re-reading its own conclusion; self-preference and judge overconfidence are measured effects, not slurs) · T3 the Commander. Facts close at T0+; judgment closes at T3. Self-grades ride at [O] until elevated.
6. **REFLECTION TRIGGERS (non-optional mid-flight).** A running directive MUST append a reconsideration note at any of: 2 REPLANs hit · 50% of budget consumed · any validator FAIL during execution · scope grew beyond the recorded success predicate. The loop does not just run on.
7. **CLOSE IT** — exactly one terminal state in the ledger row:
   **CLOSED** (evidence ref) · **PARKED** (reason + who owes) · **AMENDED** (II.2 — misses recorded, never erased) · **ESCALATED** (🔴 proposal) · **ROLLED-BACK** (first live run damaged state: revert via patch, file the failure as a BUILD CUE + replay fixture BEFORE the directive may be re-proposed — no silent retry).
8. **FILE** — shrine heartbeat with the closure (II.9). Unfiled = unfinished.

## THE CURATION GATE (v1.1 — the headline law)
A session may PROPOSE scaffolds, cues, styles, and directives. **No self-authored procedure
self-promotes.** Promotion into `scaffolding/core/` INDEX or the standing registry requires
**Commander ratification**, or **validator verification + independent use by a second
session** (both, not either-or alone: the machine proves form; a stranger proves use).
Field evidence: curated skills +16.2pp vs self-generated −1.3pp on SkillsBench [R]
(SoK: Agentic Skills, 2026, arXiv:2602.20867) — self-authored procedure degrades
performance until curated. Registry row: **SD-GOV-012**.

## THE COMPRESSION LADDER (v1.1 — how records earn promotion, and decay)
`temporal_lobe` episode (evidence, ~5–20×) → **cue line** (procedure, ~50–500×; earns its
line from ≥1 CLOSED episode) → **registry directive** (law, ~1,000×+; earns its row from a
cue that fired in ≥2 sessions with the same verdict) [R: Experience Compression Spectrum,
2026, arXiv:2604.15877 — RADIATION runs the adaptive version the survey calls missing].
Decay (Ebbinghaus, verification-weighted): CLOSED records compress upward as they cool;
**verified directives (2+ upheld fires) outlive untested ones** at review; superseded ones
move to lessons with provenance kept (never silently deleted — II.2/II.4).
