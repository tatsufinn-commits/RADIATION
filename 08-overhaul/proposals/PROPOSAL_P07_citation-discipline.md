## B. EVIDENCE_TAXONOMY.md — new sections 5–8 (full staged text)

### §5 CITATION FORMAT ANNEX
| Source type | Required shape | Example |
|---|---|---|
| Statute | instrument (number/year) + edition if IRR-versioned + locator | `PD 1096 (2005 Revised IRR), Rule VIII, Table VIII.1` |
| Statute ↔ IRR pair | cite BOTH when wording differs — the IRR is what practitioners apply | `RA 9514, Sec. 10.2.5.2; RIRR 2019, Rule 10, §10.2.5.2` |
| Code/standard (non-govt) | standard + clause + edition, with P-04 copyright posture | `NSCP 2015, Sec. 208.5 (clause cited; text not reproduced)` |
| Textbook | author, *Title*, edition, page | `Ching, *Architecture: Form, Space, and Order*, 4th ed., p. 42` |
| Lecture/curriculum | course code, material type, deck/page, date | `AR173-1P, Module 1 lecture deck, slide 14 (2026 lecture)` |
| Web | publisher + page title + locator + accessed date; never a bare URL | `DPWH, "PD 1096 IRR full text," Rule VIII, accessed 2026-09-14` |
**Negative rules:** a bare URL is not a citation · a citation without a locator is not a citation · an uncited number is `[STATUS: UNCONFIRMED]` by definition · aggregators may LOCATE a primary (label `pointer:`) but may not BE the authority.

### §6 THE [D]-as-taught MODIFIER (name kept — NOT renamed to [D-c]; rationale: 10+ existing files already carry the spelled-out form; a rename would force retro-edits II.2 discourages. P-08 mapping table must use "[D]-as-taught".)
Claim asserted by institution-authored teaching material (lecture deck, syllabus, official course module) with registered provenance (course code + deck + date or K-ID). Authoritative for curriculum and examination purposes; NOT triangulated; needs no elevation for study artifacts (@Drill, modules, flashcards). PROHIBITIONS: never the sole support of a Core card's canonical claim; never presented externally as a national standard. Lifecycle: verification_frequency = 1 curriculum year.

### §7 PUBLISHER RULE FOR [R]
[R] only where the source is peer-reviewed OR formally published by an identifiable publisher/institution (textbook house, professional body, government agency, university). Reviews/encyclopaedias/aggregators enter at [O]; blogs, forums, Q&A, content platforms capped [O]/[N] (I.2) and Tier-X/4 (P-04). The citation must NAME the publisher. Validator blocklist (check 19, live): grokipedia.com · scribd.com · fiveable.me · coursehero.com · studocu.com · flickr.com · planningtank.com · blogspot.* · medium.com — blocklisted domains remain lawful as `pointer:` locators. The rule is about the PUBLISHER, not the host string: genuinely peer-reviewed work on an odd host still qualifies.

### §8 CURRICULUM PRIMACY
For licensure-domain subjects the exam-relevant authority order is: (1) official instrument (statute/IRR/code) · (2) curriculum as taught (registered [D]-as-taught) · (3) established reference literature. (3) may annotate, deepen, contextualise — never silently overrule. Divergences carry an ⚑ EXAM NOTE (curriculum term = answer of record; literature term + author/year/page = essay depth; study guidance line) AND a CONFLICT_REGISTER row (I.5). Resolving into a recommendation is allowed; silently editing the curriculum's terminology out of an artifact is not.
**Boundary conditions:** applies to scope/terminology/values TAUGHT, not to facts about the world (a wrong historical date is still corrected by evidence) · a statute outranks a lecture that misstates it (1 > 2) · literature is not silenced — it drives the note and the depth; it just does not vote last. Curriculum Primacy changes what counts as EXAM authority, never what counts as VERIFIED — Core admission floors (I.3) untouched.
