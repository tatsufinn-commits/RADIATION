# 🔢 VERSIONING GUIDE (`VERSIONING_GUIDE.md`)
## Knowledge-Release Semantic Versioning for RADIATION
**Version:** 1.0.0

## REPOSITORY VERSION: MAJOR.MINOR.PATCH
- **MAJOR** — constitutional change: any amendment to docs/AI_RULES.md law text,
  mode definitions, or Autonomous Scan rules. (🟠 Patches, Commander-ratified.)
- **MINOR** — canon change: new/changed core scaffolds, core styles, subskills,
  or structural folders. (🟠 Patches.)
- **PATCH** — content growth: Brain promotions, dossiers, Core cards, lexicon
  entries, generated scaffolds, register appends. (🟢 Patches.)

## RULES
1. The current version lives in docs/SYSTEM_STATE.md and is updated by the
   Commander at Patch application (the push IS the release).
2. Patch zips carry their own timestamped names (II.7.2) independent of repo
   version; PATCH_NOTES.md states which version component the Patch bumps.
3. History is never rewritten (II.2): version bumps are recorded in the
   Amendment Log (constitutional) or the Patch Ledger (everything else).
4. Founding release: **v1.0.0** (2026-09-12, Blueprint v5.0 ratified).
